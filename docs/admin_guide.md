# Руководство модератора и администратора

На портале две служебные роли. Модератор — сотрудник центра карьеры, который ведёт
повседневную работу клуба. Администратор отвечает за учётные записи, справочники,
импорт и отчёты; ему доступны и все разделы модератора.

## 1. Кабинет модератора

После входа ссылка «Личный кабинет» открывает обзор: сколько заявок ждут рассмотрения,
сколько обращений без ответа, сколько мероприятий впереди.

### 1.1. Заявки на вступление

1. Откройте «Заявки на вступление». По умолчанию показаны заявки со статусом «На рассмотрении».
2. Откройте заявку. Портал сам ищет заявителя в реестре выпускников по фамилии, имени и году
   выпуска и показывает результат: зелёная плашка — найден, жёлтая — совпадений нет.
3. Нажмите «Одобрить заявку» или укажите причину и нажмите «Отклонить заявку».

При одобрении портал создаёт учётную запись и профиль выпускника, сохраняет сведения о согласии
на обработку персональных данных и показывает временный пароль. Передайте его выпускнику,
если письмо с паролем не дошло.

### 1.2. Члены клуба

Раздел «Члены клуба» — реестр действующих членов с поиском по фамилии или почте и отбором
по факультету.

### 1.3. Содержимое портала

Разделы «Новости и истории», «Мероприятия», «Партнёры», «Вакансии», «Галерея», «Документы»
устроены одинаково: список записей и кнопки «Добавить», «Изменить», «Удалить».

- Новость без даты публикации сохраняется как черновик и посетителям не видна.
- Мероприятие видно в афише при статусах «Регистрация открыта», «Завершено», «Отменено».
  Запись возможна только при статусе «Регистрация открыта».
- Число мест мероприятия нельзя сделать меньше числа уже записавшихся.
- Изображения: JPG, PNG, WEBP до 5 МБ. Документы: PDF, DOC, DOCX, RTF, ODT до 5 МБ.

### 1.4. Участники мероприятия

В списке мероприятий нажмите «Участники». На странице можно отметить посещение
и выгрузить список в файл Excel кнопкой «Выгрузить в .xlsx».

### 1.5. Обращения и отклики

- «Обращения» — сообщения из формы обратной связи. Откройте обращение, напишите ответ
  и нажмите «Сохранить ответ»: ответ уйдёт на почту заявителя, обращение станет обработанным.
- «Отклики на вакансии» — список откликов с резюме для передачи партнёрам.

## 2. Панель администратора

| Страница | Назначение |
|---|---|
| Статистика | Число членов клуба, распределение по факультетам и годам выпуска, заявки по статусам |
| Пользователи | Поиск, смена роли, отключение учётной записи, добавление сотрудника |
| Факультеты, Направления подготовки | Справочники для форм и импорта |
| Импорт выпускников | Загрузка реестра выпускников из файла Excel |
| Отчёты | Отчёт о деятельности клуба в Word, реестр членов клуба в Excel |
| Журнал действий | Кто, когда и что изменил |

### 2.1. Импорт реестра выпускников

1. На странице «Импорт выпускников» скачайте шаблон файла.
2. Заполните столбцы: Фамилия, Имя, Отчество, Код направления, Год выпуска.
3. Загрузите файл. Портал проверит каждую строку.

Если ошибок нет, записи добавятся или обновятся. Если есть хотя бы одна ошибка, ничего
не загрузится, а в протоколе будут номера строк с ошибками. В одном файле — до 2000 строк.

### 2.2. Отчёт о деятельности клуба

На странице «Отчёты» укажите период и нажмите «Сформировать отчёт». Портал отдаст файл Word
с показателями за период, списком мероприятий и составом клуба по факультетам.

### 2.3. Учётные записи

- Учётные записи выпускников создаются только при одобрении заявки.
- Модератора или администратора добавляет администратор на странице «Пользователи».
  Временный пароль показывается один раз.
- Собственную учётную запись отключить нельзя: это защита от потери доступа к панели.

## 3. Установка и обновление

Локальный запуск на Windows: дважды щёлкните `start.bat`.

Размещение на сервере:

```
pip install -r requirements-prod.txt
python manage.py migrate
python manage.py collectstatic --no-input
gunicorn alumni_portal.wsgi
```

Переменные окружения перечислены в файле `README.md`. На сервере обязательно задайте
`SECRET_KEY`, `DEBUG=0`, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, `DATABASE_URL`.

Перед обновлением сделайте резервную копию базы данных. После обновления откройте адрес
`/healthz/`: ответ `{"status": "ok"}` означает, что портал и база данных работают.

## 4. Персональные данные

Демонстрационная версия работает только с вымышленными данными (команда `seed_demo`).
Реальные данные выпускников допускается вносить только на сервере, расположенном
на территории Российской Федерации.
