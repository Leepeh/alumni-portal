# Портал клуба выпускников

Учебный проект: интернет-портал клуба выпускников образовательной организации.
Разрабатывается в рамках преддипломной практики и выпускной квалификационной работы.
Портал автоматизирует работу Центра карьеры, практики и трудоустройства с выпускниками:
приём заявок на вступление, реестр членов клуба, мероприятия, вакансии партнёров, отчётность.

## Стек

| Средство | Версия | Назначение |
|---|---|---|
| Python | 3.12 | язык серверной части |
| Django | 5.2 | веб-фреймворк |
| PostgreSQL | 17 | СУБД на хостинге (локально для разработки — SQLite) |
| Bootstrap | 5.3 | адаптивная вёрстка |
| openpyxl | 3.1 | чтение и формирование файлов .xlsx |
| python-docx | 1.2 | формирование документов .docx |
| Pillow | 13 | обработка загружаемых фотографий |
| whitenoise | 6.12 | раздача статических файлов |

CMS и готовые плагины не используются. Все модули написаны в рамках проекта.

## Возможности

- **Публичная часть:** главная, о клубе, новости с поиском, мероприятия, истории выпускников,
  вакансии, партнёры, галерея, документы, политика обработки персональных данных, контакты
  с формой обратной связи, заявка на вступление, вход.
- **Личный кабинет выпускника:** обзор, профиль с фотографией, мои мероприятия, мои отклики,
  уведомления, согласия на обработку персональных данных, смена пароля.
- **Кабинет модератора:** заявки на вступление с проверкой по реестру выпускников, реестр членов клуба, обращения,
  новости и истории, мероприятия со списком участников, партнёры, вакансии, отклики,
  галерея, документы.
- **Панель администратора:** статистика, пользователи и роли, справочники факультетов
  и направлений, импорт реестра выпускников из .xlsx, отчёты, журнал действий.
- **Документы:** список участников мероприятия и реестр членов клуба в .xlsx,
  отчёт о деятельности клуба за период в .docx.

## Роли и демонстрационные учётные записи

Команда `seed_demo` создаёт три учётные записи для проверки ролей.
Все персональные данные в демонстрационной базе вымышлены.

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | admin@alumni-club.example | Admin-2026-club |
| Модератор | moderator@alumni-club.example | Moder-2026-club |
| Выпускник | alumnus@alumni-club.example | Alumnus-2026-club |

## Запуск для разработки

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Портал откроется по адресу http://127.0.0.1:8000/

## Размещение на сервере

```
pip install -r requirements-prod.txt
python manage.py migrate
python manage.py collectstatic --no-input
gunicorn alumni_portal.wsgi
```

Файл `requirements-prod.txt` добавляет к основным библиотекам веб-сервер приложений gunicorn
и драйвер PostgreSQL. Файл `Procfile` описывает те же команды для хостингов, которые его читают.
Адрес `/healthz/` отвечает `{"status": "ok"}`, если портал и база данных работают.

## Полезные команды

| Команда | Назначение |
|---|---|
| `python manage.py test` | запуск автотестов |

## База данных

База содержит 22 прикладные таблицы: `roles`, `users`, `notifications`, `faculties`, `programs`,
`alumni_profiles`, `graduate_records`, `request_statuses`, `membership_requests`, `pd_consents`,
`news_categories`, `news`, `event_statuses`, `events`, `event_registrations`, `partners`,
`vacancies`, `vacancy_responses`, `feedback`, `gallery_photos`, `club_documents`, `action_log`.

Структура создаётся миграциями Django. В каталоге `db/` лежат:

- `alumni_portal_demo.sql` — скрипт создания и заполнения базы;
- `alumni_portal_demo.sqlite3` — готовая демонстрационная база.

## Персональные данные

Демонстрационная версия работает только с вымышленными данными. При промышленной эксплуатации
база данных размещается на серверах на территории Российской Федерации в соответствии
с частью 5 статьи 18 Федерального закона № 152-ФЗ «О персональных данных».
