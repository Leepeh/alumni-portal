# Портал клуба выпускников

Учебный проект: интернет-портал клуба выпускников образовательной организации.
Разрабатывается в рамках преддипломной практики и выпускной квалификационной работы.

## Стек

- Python 3.12
- Django 5.2
- PostgreSQL (на хостинге), SQLite (локальная разработка)
- Bootstrap 5

## Запуск для разработки

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Портал откроется по адресу http://127.0.0.1:8000/

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | секретный ключ Django |
| `DEBUG` | `1` для разработки, `0` для хостинга |
| `ALLOWED_HOSTS` | список доменов через запятую |
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `PORTAL_AUTHOR` | ФИО автора для подвала сайта |
